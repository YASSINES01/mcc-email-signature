Gmail Installation Guide

  1. Click Copy Signature in this generator.
  2. Open Gmail and click the gear icon ⚙️ (Settings).
  3. Select See all settings.
  4. Scroll down to the Signature section.
  5. Click Create new and name it.
  6. Paste (Ctrl+V / Cmd+V) directly into the text box.
  7. Set your Signature Defaults for new emails and replies.
  8. Scroll to the very bottom and click Save Changes.
